# Bernard Njiru Munyiri - Portfolio

Welcome to the repository for my personal portfolio website. 

## About
I am a Web Developer and Data Analyst based in Nairobi, Kenya. This site showcases the websites I've built, the tools I use, and my professional certifications.

## Live Site
You can view the live site here: [https://bmunyiri.github.io/BernardNMunyiri/](https://bmunyiri.github.io/BernardNMunyiri/)

## Technologies Used
- HTML5
- CSS3 (Flexbox & CSS Grid)
- Vanilla JavaScript (Accordions, Auto-updating dates)
- Inline SVGs for iconography

## Local Development
To run this site locally:
1. Clone the repository
2. Open `index.html` in your browser, or run a local server: `python -m http.server`
